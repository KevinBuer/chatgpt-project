# 飞机突袭交通线

这是一个纯前端的 HTML5 Canvas 小游戏，主角是可前后移动的攻击机，射击随机刷新的交通载具并拾取水果补给。全部资源和逻辑都在 `index.html` 中，无需额外依赖。

## 预览方式
- **直接双击** `index.html` 在浏览器中打开。
- 或在项目根目录启动本地服务器后访问 `http://localhost:8080`：
  ```bash
  python3 -m http.server 8080
  ```
  这样可以避免浏览器本地文件跨域限制。

## 关于 Testing（测试）
- 当前项目没有自动化测试，也没有受限的“测试运行权限”。
- 如需验证，请在本地运行游戏并按以下自检项手动检查：
  - 飞机可左右/前后移动，按空格射击。
  - 击中载具会得分，未击中时生命会下降；拾取水果会回血或加分。
  - 随得分提升火力等级，射速与散射方向都会增强。
  - 顶部“难度”按钮可切换轻松/标准/硬核，刷新频率、敌方体积与生命随难度调整。
- 若要在 GitHub 中看到“Testing”结果，可以自行添加 CI（如 GitHub Actions），运行你编写的自动化测试或构建脚本。
